Rillboard for Linux and Windows

Sketch, write with your pen and organize your boards in a dedicated app window. Free to use, with your work saved on your computer.

Ubuntu, Debian and Linux Mint

Download Linux installer (.deb)

Open the download with your software installer, choose Install, then open Rillboard from Applications.

Other Linux desktops: download the portable archive, extract it and run sh rillboard/linux/install.sh.

Requires Python 3 and a desktop browser. Live teaching is currently Windows-only.

Windows

Download Windows app Download installation package

Windows 10 / 11 · 64-bit · .NET Framework 4.8 and Microsoft Edge WebView2 Runtime

Start drawing on your computer

  1. Download the app and double-click Rillboard.exe.
  2. For Desktop and Start menu shortcuts, download the installation package, extract it, then run Install Drawing.cmd.
  3. Next time, open Rillboard from your shortcut.

Already using the project folder? Open Rillboard.exe inside app. The app works offline, with no account or subscription.
